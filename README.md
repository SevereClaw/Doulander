# Doulander (Downloader)

Программа с окном для скачивания видео и музыки с YouTube, VK, TikTok и ещё 1000+ сайтов.
Работает на [yt-dlp](https://github.com/yt-dlp/yt-dlp), интерфейс — [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).

## Что умеет

- Видео до 4K в MP4, MKV или WEBM
- Аудио в MP3, M4A, OPUS, FLAC или WAV
- Скачивание фрагмента: например, только с 1:20 до 3:45
- Cookies из браузера (Firefox, Chrome, Edge, Яндекс, Opera, Brave) или из файла cookies.txt —
  для видео 18+, закрытых видео и сайтов, где нужен вход в аккаунт
- Очередь ссылок, до 5 загрузок одновременно
- Плейлисты, субтитры, обложка и теги в файле
- Своя папка для загрузок, тёмная и светлая тема
- Ctrl+V при любой раскладке, меню по правой кнопке
- Превью: обложка, название, автор, длительность и примерный размер файла
- Перехват ссылок из буфера обмена (переключатель «Ловить ссылки из буфера»)
- Проверка обновлений прямо из программы
- История загрузок с поиском: открыть файл, показать в папке, скачать снова
- Перетаскивание ссылок из браузера прямо в окно (а также файлов .url и .txt)
- Значок в трее, уведомление Windows и звук, когда всё скачано

## Как получить готовую программу

### Вариант 1 — собрать на GitHub (Python не нужен)

1. Вкладка **Actions** → **Сборка Downloader** → **Run workflow**.
2. Через 3–5 минут открой запуск → внизу **Artifacts** → скачай **Downloader**.

### Вариант 2 — выпустить новую версию (Release)

1. Поменяй `APP_VERSION` в `downloader.py`, например на `1.0.1`.
2. Закоммить и создай тег:
   ```
   git tag v1.0.1
   git push origin main --tags
   ```
3. GitHub сам соберёт программу и выложит `Downloader.zip` во вкладку **Releases**.

### Вариант 3 — собрать у себя

Нужен Python с галочкой «Add python.exe to PATH». Запусти `build.bat` —
рядом появится папка `Downloader` с `Downloader.exe`, `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` и `deno.exe`.

## Обновление

Запусти `update.bat` из папки с программой. Он:

1. скачает `Downloader.exe` из последней удачной сборки на GitHub (только его, ~15 МБ);
2. обновит yt-dlp и докачает ffmpeg и deno, если их нет;
3. при необходимости обновит и сам себя.

Репозиторий закрытый, поэтому нужен [GitHub CLI](https://cli.github.com/).
`update.bat` сам предложит его установить и один раз попросит войти в GitHub через браузер.
