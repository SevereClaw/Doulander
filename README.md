# Doulander (Downloader)

Программа с окном для скачивания видео и музыки с YouTube, VK, TikTok и ещё 1000+ сайтов.
Работает на [yt-dlp](https://github.com/yt-dlp/yt-dlp), интерфейс — [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).

## Что умеет

- Поиск по названию: вместо ссылки пишешь «Король и Шут — Лесник» — скачивается первый
  результат с YouTube; кнопка «📋 Список» — сразу много песен или ссылок, по одной на строку
- yt-dlp тихо обновляется сам раз в день — YouTube не «ломается» из-за старой версии
- Видео до 4K в MP4, MKV или WEBM
- Аудио в MP3, M4A, OPUS, FLAC или WAV
- Для музыки: квадратная обложка как у альбома, выравнивание громкости,
  тексты песен в файле .lrc (из субтитров клипа)
- Скачивание фрагмента: например, только с 1:20 до 3:45
- Cookies из браузера (Firefox, Chrome, Edge, Яндекс, Opera, Brave) или из файла cookies.txt —
  для видео 18+, закрытых видео и сайтов, где нужен вход в аккаунт
- Очередь ссылок, до 5 загрузок одновременно
- Плейлисты, субтитры, обложка и теги в файле
- Своя папка для загрузок, тёмная и светлая тема
- Ctrl+V при любой раскладке, меню по правой кнопке
- Превью: обложка, название, автор, длительность и примерный размер файла
- Перехват ссылок из буфера обмена (переключатель «Ловить ссылки из буфера»)
- Проверка обновлений прямо из программы
- Кнопка «Обновить компоненты»: yt-dlp и deno обновляются на месте, недостающее
  докачивается в папку программы (программа сама предложит это при запуске)
- История загрузок с поиском: открыть файл, показать в папке, скачать снова
- Меню по правой кнопке у каждой загрузки и в истории: открыть, показать в папке,
  скачать снова, копировать ссылку, удалить файл в Корзину
- Перетаскивание ссылок из браузера прямо в окно (а также файлов .url и .txt)
- Значок в трее, уведомление Windows и звук, когда всё скачано
- «Без рекламы»: вырезает рекламные вставки из YouTube-видео (SponsorBlock)
- «Разбить по главам»: длинный микс или альбом сохраняется отдельными треками
- Пауза и продолжение — у каждой ссылки и для всех сразу; недокачанное сохраняется
  и продолжается даже после перезапуска программы
- Раскладка по папкам (по каналу, сайту, месяцу) и шаблон имени файла, в том числе свой
- Окно ⚙ Настройки: тема, трей, звук, автозапуск с Windows, cookies, папки и имена
- Прокси для YouTube: если YouTube открывается только с VPN, программа качает через
  локальный прокси VPN-программы (v2rayN, Hiddify, Nekoray, Clash…) — кнопка «Найти» ищет его сама

## Как получить готовую программу

### Вариант 0 — установщик (проще всего, можно дать другу)

Actions → последний запуск → Artifacts → **DownloaderSetup**. Внутри `DownloaderSetup.exe`:
ставит программу без прав администратора, создаёт ярлыки на рабочем столе и в «Пуске»,
появляется в «Установка и удаление программ». Видео по умолчанию сохраняются в «Загрузки\Downloader».

### Вариант 1 — собрать на GitHub (Python не нужен)

1. Вкладка **Actions** → **Сборка Downloader** → **Run workflow**.
2. Через 3–5 минут открой запуск → внизу **Artifacts** → скачай **Downloader**.

### Вариант 2 — выпустить новую версию (Release)

1. Поменяй `APP_VERSION` в `downloader.py`, например на `1.0.1`.
2. Закоммить и создай тег:
   ```
   git tag v1.0.1
   git push origin main --tags
   ```
3. GitHub сам соберёт программу и выложит `Downloader.zip` во вкладку **Releases**.

### Вариант 3 — собрать у себя

Нужен Python с галочкой «Add python.exe to PATH». Запусти `build.bat` —
рядом появится папка `Downloader` с `Downloader.exe`, `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` и `deno.exe`.

## Обновление

Запусти `update.bat` из папки с программой. Он:

1. скачает `Downloader.exe` из последней удачной сборки на GitHub (только его, ~20 МБ);
2. обновит на месте то, что уже лежит в папке: yt-dlp (`yt-dlp -U`) и deno (`deno upgrade`);
   ffmpeg обновлять не нужно — если он есть, его не трогают;
   заново скачивается только то, чего в папке нет;
3. при необходимости обновит и сам себя.

Репозиторий закрытый, поэтому нужен [GitHub CLI](https://cli.github.com/).
`update.bat` сам предложит его установить и один раз попросит войти в GitHub через браузер.

## Автопроверка

После каждой сборки GitHub запускает `Downloader.exe --selftest`: программа открывает окно
и скачивает тестовое видео в MP4, MKV, MP3 и FLAC (с вырезанием фрагмента).
Отдельно проверяются раскладка по папкам, свой шаблон имени и музыкальные функции
(на тестовой странице `tests/clip.html`: квадратная обложка, громкость около −14 LUFS, текст .lrc).
Если что-то сломалось, сборка помечается красным, и `update.bat` её не скачает.
Отдельно, для информации, проверяется скачивание с YouTube.
