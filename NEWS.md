# Что нового в Downloader

Верхний раздел попадает в описание релиза и в окно обновления программы.

## 1.20.0
- Обновление теперь прямо в программе: окно «Доступно обновление» показывает, что изменилось, и скачивает новую версию с полосой загрузки — чёрного окна с update.bat больше нет.
- Нажали «Обновить сейчас» — программа закрывается на несколько секунд и открывается уже новой. Очередь, история и настройки остаются.
- Для обновления больше не нужны GitHub CLI и вход в GitHub.
- Скачивается только сама программа (десятки мегабайт), ffmpeg и yt-dlp не перекачиваются.

## 1.19.1
- Папка с файлом открывается после скачивания (настройка включена по умолчанию).

## 1.19.0
- Название в очереди растягивается на всю ширину окна.
- Поиск по названию показывает результаты YouTube на выбор.
